# Contributing

Bug reports and small pull requests are welcome.

Before opening a pull request:

1. Keep the extension dependency-free and easy to read.
2. Test changes on both current and old Reddit when they affect page matching.
3. Run `npm test` and `npm run package`.
4. Explain the problem and the behavior your change introduces.

Reddit changes its markup from time to time. If a filter stops working, include the browser, Reddit layout, affected page, and enough detail to reproduce it. Do not include private account information in issues or screenshots.

For security problems, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
